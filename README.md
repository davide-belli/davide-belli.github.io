# Davide Belli - Personal Website

Personal academic website showcasing research work, publications, and achievements.

## 🌐 Live Site

[https://davide-belli.github.io](https://davide-belli.github.io)

## 📋 Pages

- **Home**: Professional bio, education, and contact information
- **Research**: Publications and patents
- **Awards**: Competitive programming achievements and service

## 🛠️ Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- No frameworks - lightweight and fast
- Fully responsive design

## 📁 Structure

```
website1/
├── index.html          # Home page
├── research.html       # Publications & Patents
├── awards.html         # Awards & Service
├── css/style.css       # Styles
├── js/main.js          # Mobile menu
└── assets/             # Images and resources
```

## 🚀 Local Development

```bash
# Clone and open
git clone https://github.com/davide-belli/website1.git
cd website1
open index.html
```
